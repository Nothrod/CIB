CLUB INFORMATIQUE DE BETHONCOURT — INSTALLATION

1. Décompressez cette archive ZIP.
2. Déposez index.html et logo.png dans le dossier web de votre domaine (souvent public_html ou www), au même niveau.
3. Ouvrez votre nom de domaine dans votre navigateur.

Sauvegardez les anciens fichiers avant de remplacer une page existante.

Le site est statique : aucune installation, base de données, dépendance Node.js ou connexion ChatGPT nécessaire.
La mise en page et les styles sont intégrés dans index.html.
La carte Google Maps nécessite une connexion Internet.
Les boutons téléphone, email et itinéraire ouvrent les applications ou services correspondants.

Pour modifier les textes, horaires et tarifs : ouvrez index.html dans un éditeur de texte.
Pour changer le logo : remplacez logo.png en conservant ce nom.
